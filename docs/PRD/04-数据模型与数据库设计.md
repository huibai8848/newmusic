## 1. 设计总则

| 编号 | 规则 |
|---|---|
| DD-01 | 存储引擎 `InnoDB`，字符集 `utf8mb4`，排序规则 `utf8mb4_0900_ai_ci` |
| DD-02 | 主键 `id BIGINT UNSIGNED`，**雪花算法**生成（MyBatis-Plus `ASSIGN_ID`），不使用自增 |
| DD-03 | 所有表含公共字段：`create_time`、`update_time`、`create_by`、`update_by`、`deleted` |
| DD-04 | 逻辑删除用 `deleted TINYINT`（0=未删 1=已删），MyBatis-Plus `@TableLogic` |
| DD-05 | **不建物理外键**，关联完整性由应用层保证（便于分库与数据迁移） |
| DD-06 | 高频更新字段（计数类）独立冗余，异步校准，不实时 JOIN 聚合 |
| DD-07 | 枚举值用 `TINYINT` + 代码注释；字典用 `t_sys_dict` 管理可配置枚举 |
| DD-08 | 金额统一用 `BIGINT` 存**分**（避免浮点误差）；比例用 `DECIMAL(6,4)` |
| DD-09 | 单表行数预计 > 500 万时，必须设计分表或归档策略（见第 5 节） |
| DD-10 | 索引命名 `idx_{表简写}_{字段}`、`uk_{表简写}_{字段}`；单表索引 ≤ 6 个 |


## 2. 用户域（user）

### 2.1 t_user — 用户主表

```sql
CREATE TABLE `t_user` (
  `id`            BIGINT UNSIGNED NOT NULL COMMENT '用户ID(雪花)',
  `username`      VARCHAR(50)     NOT NULL COMMENT '用户名(唯一,登录用)',
  `phone`         VARCHAR(20)     DEFAULT NULL COMMENT '手机号(加密存储,AES)',
  `phone_hash`    CHAR(64)        DEFAULT NULL COMMENT '手机号SHA256(用于唯一查询)',
  `email`         VARCHAR(100)    DEFAULT NULL COMMENT '邮箱',
  `password`      VARCHAR(100)    NOT NULL COMMENT '密码(BCrypt,strength=10)',
  `nickname`      VARCHAR(50)     NOT NULL COMMENT '昵称',
  `avatar`        VARCHAR(500)    DEFAULT NULL COMMENT '头像URL',
  `gender`        TINYINT         NOT NULL DEFAULT 0 COMMENT '性别 0未知 1男 2女',
  `birthday`      DATE            DEFAULT NULL COMMENT '生日',
  `signature`     VARCHAR(200)    DEFAULT NULL COMMENT '个性签名',
  `user_type`     TINYINT         NOT NULL DEFAULT 1 COMMENT '用户类型 1普通 2运营 3管理员 4超管',
  `status`        TINYINT         NOT NULL DEFAULT 1 COMMENT '状态 0待验证 1正常 2封禁 3注销中 4已注销',
  `ban_reason`    VARCHAR(200)    DEFAULT NULL COMMENT '封禁原因',
  `ban_until`     DATETIME(3)     DEFAULT NULL COMMENT '封禁到期时间(NULL=永久)',
  `register_ip`   VARCHAR(45)     DEFAULT NULL COMMENT '注册IP',
  `last_login_time` DATETIME(3)   DEFAULT NULL COMMENT '最后登录时间',
  `last_login_ip` VARCHAR(45)     DEFAULT NULL COMMENT '最后登录IP',
  `vip_level`     TINYINT         NOT NULL DEFAULT 0 COMMENT '会员等级 0非会员(预留)',
  `vip_expire_time` DATETIME(3)   DEFAULT NULL COMMENT '会员到期时间(预留)',
  `create_time`   DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `update_time`   DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  `create_by`     BIGINT UNSIGNED DEFAULT NULL,
  `update_by`     BIGINT UNSIGNED DEFAULT NULL,
  `deleted`       TINYINT         NOT NULL DEFAULT 0,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_username` (`username`),
  UNIQUE KEY `uk_user_phone_hash` (`phone_hash`),
  KEY `idx_user_status` (`status`, `deleted`),
  KEY `idx_user_nickname` (`nickname`),
  KEY `idx_user_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

**规则说明**：
- `phone` 用 AES-256 加密存储，`phone_hash` 用于唯一性校验与登录查询（等值匹配）。
- `password` 用 BCrypt（strength=10），**不可逆**。
- `ban_until` 为 `NULL` 且 `status=2` 表示永久封禁。
- 已注销用户（`status=4`）保留 `id` 与匿名化 `nickname`（"已注销用户"），关联内容不删除。

```sql
  `copyright_status` TINYINT NOT NULL DEFAULT 0 COMMENT '版权 0未授权 1已授权 2已过期 3受限',
  `copyright_owner`  VARCHAR(200) DEFAULT NULL COMMENT '版权方',
  `copyright_expire` DATE DEFAULT NULL COMMENT '版权到期日',
  -- 统计（冗余，Redis 为准，定时同步）
  `play_count`     BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '播放量',
  `like_count`     BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '点赞数',
  `collect_count`  BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '收藏数',
  `comment_count`  BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '评论数',
  `share_count`    BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '分享数',
  `download_count` BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '下载数',
  `hot_score`      INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '热度分(定时计算)',
  `completion_rate` DECIMAL(6,4) NOT NULL DEFAULT 0 COMMENT '完播率',
  -- 状态
  `audit_status`   TINYINT NOT NULL DEFAULT 0 COMMENT '审核 0待审 1通过 2拒绝',
  `status`         TINYINT NOT NULL DEFAULT 0 COMMENT '状态 0下架 1上架',
  `publish_time`   DATETIME(3) DEFAULT NULL COMMENT '上架时间',
  `sort_weight`    INT NOT NULL DEFAULT 0 COMMENT '排序权重(运营干预)',
  `source`         TINYINT NOT NULL DEFAULT 1 COMMENT '来源 1管理员录入 2第三方 3用户投稿',
  `create_time`    DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `update_time`    DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  `create_by`      BIGINT UNSIGNED DEFAULT NULL,
  `update_by`      BIGINT UNSIGNED DEFAULT NULL,
  `deleted`        TINYINT NOT NULL DEFAULT 0,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_song_isrc` (`isrc`),
  KEY `idx_song_name` (`name`),
  KEY `idx_song_artist` (`artist_id`),
  KEY `idx_song_album` (`album_id`),
  KEY `idx_song_status_hot` (`status`, `audit_status`, `hot_score`),
  KEY `idx_song_publish` (`publish_time`),
  KEY `idx_song_genre_lang` (`genre`, `language`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='歌曲表';
```

**关键规则**：

- `BR-04-001`：`status=1(上架)` 必须同时满足 `audit_status=1(审核通过)` 且 `copyright_status=1(已授权)`。服务端在更新时强校验。
- `BR-04-002`：三档音质 URL 至少存在 `audio_standard`，否则不可上架。
- `BR-04-003`：`copyright_expire` 到期前 30 天触发提醒，到期自动置 `copyright_status=2` 并下架。
- `BR-04-004`：统计字段（play_count 等）**不允许**通过普通更新接口修改，只能由统计任务/Redis 同步回写。

## 11. 分表与归档策略

| 表 | 预估年增长 | 策略 | 说明 |
|---|---|---|---|
| `t_play_history` | 10 亿+ | 按月分表 + 6 个月热数据，冷数据迁 ClickHouse | 用 ShardingSphere 或应用层路由 |
| `t_comment` | 5000 万 | 按 `target_id % 8` 分 8 表 | 应用层路由 |
| `t_private_message` | 2 亿 | 按 `conversation_id % 8` 分 8 表 | 应用层路由 |
| `t_room_message` | 10 亿 | 按月分表，保留 3 个月 | 冷数据可丢弃（弹幕价值低） |
| `t_notification` | 1 亿 | 按月分表，保留 3 个月 | 已读的定期清理 |
| `t_ai_call_log` | 5000 万 | 按日归档 ClickHouse，MySQL 保留 30 天 | 便于成本分析 |
| `t_search_history` | 1 亿 | 按月分表，保留 6 个月 | — |
| `t_operation_log` | 3000 万 | 保留 1 年（合规要求） | 不分区，加索引即可 |

### 11.1 分片键选择原则

- 分片键必须出现在**绝大多数查询条件**中（避免跨分片查询）。
- 评论按 `target_id` 分片：所有"查看某歌曲评论"都能定位单分片；"查看我的评论"需**异构索引表**或宽表。
- 私信按 `conversation_id` 分片：会话内查询天然单分片。

## 12. 索引设计原则

| 原则 | 说明 |
|---|---|
| 最左前缀 | 联合索引 `(a,b,c)` 只能用于 `a`、`a,b`、`a,b,c` |
| 覆盖索引 | 高频查询尽量让索引覆盖返回字段，减少回表 |
| 区分度优先 | 区分度高的字段放前面（`status` 只有几个值，不适合单独建索引） |
| 避免函数索引 | 禁止 `WHERE DATE(create_time) = ...`，改为范围查询 |
| 单表索引数 | ≤ 6 个（写性能考虑） |
| 慢查询阈值 | 1 秒，开启慢查询日志，纳入监控 |

### 12.1 典型查询与索引对照

| 查询场景 | SQL 模式 | 命中索引 |
|---|---|---|
| 首页热门歌曲 | `WHERE status=1 AND audit_status=1 ORDER BY hot_score DESC LIMIT 20` | `idx_song_status_hot` |
| 歌手歌曲列表 | `WHERE artist_id=? AND status=1` | `idx_song_artist` |
| 歌曲评论列表 | `WHERE target_type=1 AND target_id=? AND status=1 ORDER BY create_time DESC` | `idx_cm_target` |
| 我的关注动态 | `WHERE user_id IN (...) AND status=1 ORDER BY create_time DESC` | `idx_feed_user_time` |
| 房间在线成员 | `WHERE room_id=? AND room_role>=0` | `idx_rm_role` |
| 未读通知 | `WHERE user_id=? AND is_read=0 ORDER BY create_time DESC` | `idx_notify_user` |
| 待审任务 | `WHERE status=0 ORDER BY create_time ASC` | `idx_at_status` |

## 15. 验收标准（数据模型）

|---|---|---|
