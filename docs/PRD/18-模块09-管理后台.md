> **说明**：管理后台为**独立前端应用**（`web-admin/`），与 C 端共享后端 API 但使用独立的鉴权与权限体系。

---

## 1. 模块目标

1. 让管理员能够**高效管理**用户、歌曲、歌单、房间、评论等内容。
2. 让运营能够**配置**推荐位、Banner、热搜、场景歌单。
3. 让审核人员能够**处理**内容审核任务（机审 + 人审）。
4. 提供**数据看板**与**操作审计**，保证平台可观测、可追责。

**衡量指标**：

| 指标 | 目标 |
|---|---|
| 后台接口 P95 | ≤ 500ms |
| 列表页首屏加载 | ≤ 1.5s |
| 批量操作（100 条） | ≤ 3s |
| 审核任务处理时效 | 平均 ≤ 30 分钟 |
| 操作日志完整率 | 100%（所有写操作） |

## 3. 前置条件

- 管理员账号已创建并分配角色。
- 后台登录使用**独立入口** `/admin/login`（与 C 端登录 Token 分离，**不可**用于 C 端 API）。
- 后台接口路径统一前缀 `/api/v1/admin/**`，**必须**校验管理员角色。

## 4. 后台登录与安全

### FR-18-001 后台登录 【P0】

| 项 | 内容 |
|---|---|
| **功能目标** | 管理员安全登录，与 C 端隔离 |
| **使用角色** | 全部管理员 |

**操作流程**：

1. 访问 `/admin/login`。
2. 输入用户名 + 密码 + **图形验证码**。
3. 若该账号**开启了二次验证**（SUPER_ADMIN 强制开启），输入 TOTP 动态码。
4. 服务端校验：账号存在、状态正常、密码正确、验证码正确、具备管理员角色。
5. 登录成功 → 返回**管理员专用 Token**（与 C 端 Token 使用**不同签名密钥**）。
6. **强制**记录登录日志（IP、UA、时间、结果）。

**Token 策略**：

| 项 | 值 | 说明 |
|---|---|---|
| Access Token 有效期 | **1 小时** | 比 C 端短（后台风险更高） |
| Refresh Token 有效期 | **8 小时** | 工作时段 |
| 签名密钥 | **独立于 C 端** | 密钥泄露影响面隔离 |
| 签发者（iss） | `ml-admin` | 与 C 端 `ml-user` 区分，互相不可用 |
| 存储 | `httpOnly` Cookie（优先）或 memory | **禁止** localStorage（防 XSS 窃取） |

**业务规则**：

- `BR-18-001`：后台 Token 与 C 端 Token **完全隔离**（不同密钥、不同 iss、不同校验器）。
- `BR-18-002`：**必须**图形验证码（防暴力破解）。
- `BR-18-003`：**SUPER_ADMIN 必须**开启 TOTP 二次验证。
- `BR-18-004`：登录失败 **5 次** → 账号锁定 **30 分钟**。
- `BR-18-005`：登录失败**不区分**"账号不存在"与"密码错误"（统一提示"用户名或密码错误"）。
- `BR-18-006`：**必须**记录登录日志（含失败）。
- `BR-18-007`：**异地登录**（IP 归属地变化）**必须**发送邮件通知（SUPER_ADMIN）/ 站内通知（其他）。
- `BR-18-008`：Access Token **必须**短有效期（1h），Refresh Token **轮换**（一次性）。
- `BR-18-009`：Token **必须**支持**主动失效**（管理员被禁用/删除时立即踢下线）。
- `BR-18-010`：**禁止**在 URL 中传递 Token。
- `BR-18-011`：后台 API **必须**校验 `Referer` / `Origin`（防 CSRF）。
- `BR-18-012`：后台**必须**启用 HTTPS。
- `BR-18-013`：**建议**后台限制 IP 白名单（可配置，见系统配置）。
- `BR-18-014`：**空闲 30 分钟**自动登出（前端计时）。

**异常情况**：

| 编号 | 场景 | 处理 |
|---|---|---|
| `EX-18-001-1` | 密码错误 5 次 | `40004`，账号锁定 30 分钟 |
| `EX-18-001-2` | 验证码错误 | `40005`，刷新验证码 |
| `EX-18-001-3` | 非管理员账号尝试登录 | `40003`，统一提示（不暴露） |
| `EX-18-001-4` | 账号被禁用 | `40006`，提示"账号已被禁用" |
| `EX-18-001-5` | TOTP 码错误 | `40007`，允许重试 3 次 |
| `EX-18-001-6` | Token 过期 | `401`，前端跳登录页 |
| `EX-18-001-7` | IP 不在白名单 | `403`，拒绝访问 |
| `EX-18-001-8` | 账号被删除但 Token 未过期 | Token 校验时查库，账号不存在则拒绝 |

**验收标准**：

- `AC-18-001-1`：后台登录需验证码
- `AC-18-001-2`：C 端 Token 无法访问后台接口
- `AC-18-001-3`：后台 Token 无法访问 C 端接口
- `AC-18-001-4`：连续 5 次失败后锁定
- `AC-18-001-5`：SUPER_ADMIN 需 TOTP
- `AC-18-001-6`：登录日志完整记录
- `AC-18-001-7`：空闲 30 分钟自动登出

### FR-18-005 用户封禁/解封 【P0】

| 项 | 内容 |
|---|---|
| **功能目标** | 处置违规用户 |
| **使用角色** | 管理员 / 超管 |

**封禁类型**：

| 类型 | 说明 | 时长 |
|---|---|---|
| 临时封禁 | 指定时长 | 1h / 24h / 7d / 30d / 自定义 |
| 永久封禁 | 无限期 | — |
| 禁言 | 仅禁发言（评论/私信/房间聊天） | 指定时长或永久 |
| 禁止登录 | 无法登录 | 指定时长或永久 |

**操作流程**：

1. 在用户列表/详情点击"封禁"。
2. 选择**封禁类型** + **时长** + **原因**（必填，≥ 5 字）+ 可选**证据截图**。
3. 二次确认。
4. 执行封禁：
   - 更新 `t_user.status` / `ban_until` / `ban_reason`
   - **踢下线**（清除所有 Token 与 WebSocket 连接）
   - 清缓存
   - 写操作日志
   - **通知用户**（站内通知 + 邮件，说明原因与时长）
5. 用户端立即生效：下次请求 `40008`（"账号已被封禁，原因：xxx，解封时间：xxx"）。

**业务规则**：

- `BR-18-034`：**原因必填**且 ≥ 5 字。
- `BR-18-035`：封禁**必须**立即踢下线（清 Token + 断 WebSocket）。
- `BR-18-036`：**必须**通知用户（否则用户不知道为什么被封，导致客服压力）。
- `BR-18-037`：**临时封禁到期自动解封**（定时任务每 5 分钟扫描）。
- `BR-18-038`：封禁**必须**记录操作日志与 IP。
- `BR-18-039`：**解封**同样需要填写原因。
- `BR-18-040`：**永久封禁**仅 ADMIN/SUPER_ADMIN 可操作，需二次确认。
- `BR-18-041`：**同一用户被封禁**时再次封禁 → 覆盖（更新时长）。
- `BR-18-042`：被封禁用户**仍可访问**"申诉"页面（见 [27 章](./27-模块18-内容安全.md)）。
- `BR-18-043`：封禁操作**必须**可从"操作记录"中追溯。
- `BR-18-044`：**批量封禁**（最多 100 个）用于批量处置（如刷量账号）。

**异常情况**：

| 编号 | 场景 | 处理 |
|---|---|---|
| `EX-18-005-1` | 封禁自己是超管 | 拒绝（防止自锁） |
| `EX-18-005-2` | 封禁操作失败（部分成功） | 返回失败列表，允许重试 |
| `EX-18-005-3` | 用户正在播放 | 踢下线，前端提示"账号已被封禁" |
| `EX-18-005-4` | 已封禁用户再次被封 | 覆盖更新 |
| `EX-18-005-5` | 通知发送失败 | 不阻断封禁（记录失败日志） |

**验收标准**：

- `AC-18-005-1`：封禁需填原因
- `AC-18-005-2`：封禁后用户立即被踢下线
- `AC-18-005-3`：封禁后用户收到通知
- `AC-18-005-4`：临时封禁到期自动解封
- `AC-18-005-5`：封禁记录操作日志
- `AC-18-005-6`：不能封禁自己
- `AC-18-005-7`：批量封禁可用

## 14. 后台监控与安全

| 项 | 要求 |
|---|---|
| 登录监控 | 失败次数、锁定次数、异地登录 |
| 越权监控 | 403 次数按管理员聚合，异常升高告警 |
| 敏感操作监控 | 查看手机号、查看私信、导出数据、危险操作的次数与人员 |
| 操作频率监控 | 单管理员 5 分钟内操作 > 200 次 → 告警（可能脚本化） |
| 会话监控 | 在线管理员列表，可强制下线 |
| 数据脱敏 | 手机号、邮箱、身份证、Token 一律脱敏 |
| 越权测试 | 定期渗透测试（每季度） |
| 日志审计 | 每月抽查操作日志，检查异常行为 |

**告警规则**：

| 规则 | 阈值 | 级别 |
|---|---|---|
| 后台登录失败激增 | 5 分钟内 > 20 次 | 严重 |
| 敏感操作 | 单管理员 1 小时内 > 50 次查看手机号 | 警告 |
| 危险操作执行 | 任意一次 | 通知 |
| 越权访问 | 5 分钟内 > 10 次 | 警告 |
| 操作频率异常 | 单管理员 5 分钟 > 200 次 | 警告 |
