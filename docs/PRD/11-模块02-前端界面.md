## 1. 模块目标

实现 PC Web 端完整体验，并具备向移动端/PWA 平滑扩展的能力。

**衡量指标**：

- 首屏（首页）LCP ≤ 1.8s（4G 网络）
- 路由切换视觉响应 ≤ 200ms
- 播放器跨页面持续播放**零中断**（切路由不重新加载音频）
- 所有页面支持 1280px ~ 2560px 宽度自适应，无横向滚动

---

## 2. 使用角色

游客、普通用户、房主/房管、平台管理员、超管、运营 —— 全部角色均通过前端交互。

### 4.2 路由守卫

```tsx
// router/guard.tsx
export const RequireAuth = ({ children }: { children: ReactNode }) => {
  const { isLogin } = useUserStore();
  const location = useLocation();
  if (!isLogin) {
    return <Navigate to="/login" state={{ redirect: location.pathname + location.search }} replace />;
  }
  return <>{children}</>;
};

export const RequirePerm = ({ perm, children }: { perm: string; children: ReactNode }) => {
  const { perms } = useUserStore();
  if (!perms.includes(perm) && !perms.includes('*:*:*')) {
    return <ForbiddenPage />;
  }
  return <>{children}</>;
};
```

**规则**：前端守卫**仅作体验优化**，服务端必须二次校验（见 [02 章](./02-用户角色与权限矩阵.md) `BR-02-011`）。

## 5. 核心页面需求明细

### FR-11-001 首页 【P0】

| 项 | 内容 |
|---|---|
| **功能目标** | 在 3 秒内让用户找到想听的内容并开始播放 |
| **使用角色** | 全部 |
| **前置条件** | 无（游客可用，走试听降级） |

**操作流程**：

1. 用户进入 `/`。
2. 并行请求：轮播图、热门歌曲、推荐歌单、排行榜前 10、推荐音乐房（已登录则请求"每日推荐/猜你喜欢"）。
3. 骨架屏展示，数据到达后渐进渲染。
4. 点击歌曲卡片 → 加入播放队列并播放（不跳页，直接底部播放器播放）。
5. 点击歌单卡片 → 跳歌单详情页。

**页面模块（从上到下）**：

| 区块 | 内容 | 数据源 |
|---|---|---|
| 顶部导航 | Logo、搜索框、登录/头像、主题切换 | 全局 |
| 轮播图 | 运营配置 Banner，最多 5 张，自动轮播 5s | `t_banner` position=1 |
| 每日推荐（登录） | 30 首，带推荐理由 | 推荐服务，slot=`daily_recommend` |
| 猜你喜欢（登录） | 网格卡片，12 个 | 推荐服务，slot=`guess_like` |
| 热门歌曲 | 列表 Top 20，可播放 | `ml:music:hot:songs` |
| 推荐歌单 | 横滑卡片，12 个 | `t_playlist` is_recommend=1 |
| 排行榜 | 3 个榜单各 Top 5，Tab 切换 | 榜单服务 |
| 热门音乐房 | 卡片，最多 6 个 | 房间热度榜 |
| 场景歌单（P1） | 按场景分 Tab | `t_playlist` type=4 |

**业务规则**：

- `BR-11-001`：未登录时，"每日推荐/猜你喜欢"替换为"热门推荐"（内容一致但无个性化）。
- `BR-11-002`：各区块**独立请求**，单个区块失败不影响其他区块（用 `ErrorBoundary` + 局部兜底）。
- `BR-11-003`：歌曲卡片展示：封面、歌名、歌手、播放量、时长、悬停显示播放按钮。
- `BR-11-004`：游客点击播放 → 播放 30 秒试听 + 播放 25 秒时弹出"登录畅听全曲"引导。
- `BR-11-005`：所有区块数据优先读接口缓存（Redis），接口 P95 ≤ 300ms。

**异常情况**：

| 编号 | 场景 | 处理 |
|---|---|---|
| `EX-11-001-1` | 推荐接口失败 | 该区块展示"热门兜底"内容，或显示"加载失败，点击重试" |
| `EX-11-001-2` | 轮播图无数据 | 隐藏轮播区块 |
| `EX-11-001-3` | 网络离线 | 展示离线缓存内容（P2，Service Worker） |
| `EX-11-001-4` | 图片加载失败 | 显示占位图（品牌 logo 灰色版） |

**验收标准**：

- `AC-11-001-1`：首页 LCP ≤ 1.8s（4G，首访）
- `AC-11-001-2`：单个区块接口 500 时，其余区块正常展示
- `AC-11-001-3`：游客点击播放，25 秒后弹出登录引导
- `AC-11-001-4`：点击歌曲卡片不跳页，底部播放器立即播放

### FR-11-002 登录 / 注册 【P0】

| 项 | 内容 |
|---|---|
| **功能目标** | 低摩擦完成注册与登录 |
| **使用角色** | 游客 |

**登录方式**：

| 方式 | 字段 | 优先级 |
|---|---|---|
| 账号密码 | 用户名/手机号 + 密码 | P0 |
| 手机验证码 | 手机号 + 6 位验证码 | P0 |
| 图形验证码 | 登录失败 3 次后强制 | P0 |
| 第三方（微信/QQ） | OAuth | P2 |

**注册流程**：

```
输入手机号 → 点击"获取验证码" → 图形验证码校验 → 发送短信(60s 倒计时)
   → 输入短信验证码 + 设置密码 → 勾选《用户协议》《隐私政策》 → 提交
   → 注册成功 → 自动登录 → 跳转 redirect 或首页
```

**业务规则**：

- `BR-11-010`：密码强度：8-20 位，必须含**字母 + 数字**，禁止纯数字/纯字母。
- `BR-11-011`：短信验证码 60 秒内不可重发，单手机号每日上限 10 条。
- `BR-11-012`：验证码 5 分钟有效，输错 3 次作废。
- `BR-11-013`：必须勾选协议才能注册（前端拦截 + 后端校验 `agreed=true`）。
- `BR-11-014`：登录成功后 token 存 `localStorage`（access）+ `httpOnly` 不可行（纯前端），refresh 存 `localStorage`；**不使用** cookie 存 token（避免 CSRF）。
- `BR-11-015`：登录后跳转 `state.redirect`，无则跳首页。
- `BR-11-016`：连续登录失败 5 次锁定 15 分钟。

**异常情况**：

| 编号 | 场景 | 处理 |
|---|---|---|
| `EX-11-002-1` | 账号密码错误 | 显示 `20001`，不清空已填账号 |
| `EX-11-002-2` | 验证码错误 | 显示 `20002`，验证码不清空，可重输 |
| `EX-11-002-3` | 手机号已注册 | 显示 `20003` + "去登录"链接 |
| `EX-11-002-4` | 账号被封禁 | 显示封禁原因与解封时间 |
| `EX-11-002-5` | 短信发送失败 | 显示 `90006`，重置倒计时允许重试 |
| `EX-11-002-6` | 网络超时 | 按钮恢复可点击，提示重试 |

**验收标准**：

- `AC-11-002-1`：弱密码（`12345678`）被前端与后端双重拒绝
- `AC-11-002-2`：未勾选协议时提交被拦截
- `AC-11-002-3`：验证码 60s 倒计时正确，倒计时中按钮禁用
- `AC-11-002-4`：登录成功后跳转到来源页
- `AC-11-002-5`：连续失败 5 次后账号锁定 15 分钟

| **使用角色** | 全部 |

**播放器形态**：

| 形态 | 说明 | 触发 |
|---|---|---|
| **迷你播放条** | 底部固定，高 72px，全局常驻 | 默认 |
| **播放列表面板** | 右侧抽屉，展示当前队列 | 点击播放条右侧列表图标 |
| **全屏播放页** | 大封面 + 歌词 + 律动 | 点击播放条封面 / 路由 `/playing` |

```
┌────────────────────────────────────────────────────────────────────┐
│ [封面] 晴天 - 周杰伦        ⟲ ◀ ▶ ▷ ⏸ ▶ ⟳   ━━━●━━━ 1:30/4:29  🔊 ── │
│        (< 播放条固定底部，始终可见)                                    │
└────────────────────────────────────────────────────────────────────┘
```

**全局状态设计（Zustand）**：

```typescript
// stores/playerStore.ts
interface PlayerState {
  // 播放数据
  currentSong: Song | null;
  playlist: Song[];                 // 当前播放队列
  currentIndex: number;
  playMode: 'order' | 'loop' | 'single' | 'shuffle';
  shuffleOrder: number[];           // 随机播放的顺序
  // 播放控制
  isPlaying: boolean;
  isBuffering: boolean;
  currentTime: number;
  duration: number;
  volume: number;                   // 0~1
  muted: boolean;
  playbackRate: number;             // 0.5 ~ 2.0
  quality: 'standard' | 'high' | 'lossless';
  // 错误
  error: { code: number; message: string } | null;
  retryCount: number;
  // actions
  playSong: (song: Song, list?: Song[]) => void;
  playList: (list: Song[], index: number) => void;
  toggle: () => void;
  next: () => void;
  prev: () => void;
  seek: (time: number) => void;
  setVolume: (v: number) => void;
  setPlayMode: (m: PlayerState['playMode']) => void;
  setQuality: (q: PlayerState['quality']) => void;
  addToQueue: (song: Song) => void;
  removeFromQueue: (index: number) => void;
  clearQueue: () => void;
}
```

**实现要点**：

- `<audio>` 元素**挂载在 `MainLayout` 顶层**，路由切换时**不销毁**，保证持续播放。
- 播放地址**懒加载**：切换歌曲时才请求 `GET /api/v1/player/url?songId=&quality=`，不预加载全部队列（省带宽）。
- 播放地址**带过期时间**，`onError` 时若为 URL 过期则自动重新获取并续播。
- 进度更新用 `timeupdate` 事件（约 4 次/秒），用 `requestAnimationFrame` 节流渲染进度条与歌词。

**业务规则**：

- `BR-11-040`：播放队列改变（如点击新歌单播放）时，**替换**队列；`addToQueue` 为**追加**。
- `BR-11-041`：播放模式：
  - `order` 顺序播放（列表播完停止）
  - `loop` 列表循环
  - `single` 单曲循环
  - `shuffle` 随机（用 `shuffleOrder` 记录顺序，切歌不重复直到全部播完）
- `BR-11-042`：上一首在播放 > 3 秒时，行为为"回到开头"；≤ 3 秒则切上一首（业界惯例）。
- `BR-11-043`：歌曲播放到 90% 或最后 10 秒时预取下一首的播放地址。
- `BR-11-044`：无版权的歌曲自动跳过并提示。
- `BR-11-045`：播放状态持久化到 `localStorage`（当前歌曲、进度、队列、模式），刷新页面后可恢复（进度恢复需用户确认，避免自动播放被浏览器拦截）。
- `BR-11-046`：浏览器自动播放策略限制——首次播放**必须**由用户交互触发。

**异常情况**：

| 编号 | 场景 | 处理 |
|---|---|---|
| `EX-11-005-1` | 播放地址 403/过期 | 自动重新获取地址，重试 1 次 |
| `EX-11-005-2` | 音频加载失败 | 提示"播放失败"，3 秒后自动下一首，`retryCount` 递增 |
| `EX-11-005-3` | 连续 3 首失败 | 暂停播放 + 提示"网络异常，请检查网络" |
| `EX-11-005-4` | 网络中断 | 显示缓冲状态，恢复后自动续播 |
| `EX-11-005-5` | 播放中歌曲被下架 | 提示并自动下一首 |
| `EX-11-005-6` | 浏览器不支持该音频格式 | 回退到标准音质 |

**验收标准**：

- `AC-11-005-1`：从首页播放歌曲后，跳转到任意页面音乐**不中断**
- `AC-11-005-2`：播放地址过期时自动刷新并续播（用户无感知）
- `AC-11-005-3`：刷新页面后队列与当前歌曲恢复
- `AC-11-005-4`：随机播放遍历完整个队列前不重复
- `AC-11-005-5`：播放失败自动跳下一首，连续 3 次失败后暂停并提示
- `AC-11-005-6`：`order` 模式播完最后一首后停止（不循环）

## 6. 通用设计规范

### 6.1 响应式断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| `xs` | < 576 | 单列（移动端，P1） |
| `sm` | 576~768 | 单列 |
| `md` | 768~992 | 双列 |
| `lg` | 992~1200 | 主内容 + 侧边栏 |
| `xl` | 1200~1600 | 主内容 + 侧边栏 + 推荐位 |
| `xxl` | > 1600 | 内容区最大宽度 1440px，居中 |

### 6.2 主题与暗黑模式

- 使用 CSS 变量 + Ant Design 5 `ConfigProvider theme` 实现。
- 主题状态存 `localStorage`，默认跟随系统（`prefers-color-scheme`）。

```less
// variables.less
:root {
  --color-primary: #1677ff;
  --color-bg: #ffffff;
  --color-bg-elevated: #fafafa;
  --color-text: #1f1f1f;
  --color-text-secondary: #8c8c8c;
  --color-border: #f0f0f0;
}
[data-theme='dark'] {
  --color-bg: #141414;
  --color-bg-elevated: #1f1f1f;
  --color-text: #e8e8e8;
  --color-text-secondary: #8c8c8c;
  --color-border: #303030;
}
```

**规则**：所有颜色**必须**用 CSS 变量，禁止硬编码色值（否则暗黑模式失效）。

### 6.3 加载与空态

| 状态 | 表现 |
|---|---|
| 首屏加载 | 骨架屏（Skeleton），非全屏 Loading |
| 局部加载 | 区块内 Spin |
| 列表加载更多 | 底部"加载中..." + 触底自动加载 |
| 空数据 | 插画 + 文案 + 引导按钮 |
| 加载失败 | 图标 + 文案 + "重试"按钮 |
| 无网络 | 全局提示条 + 自动重试 |

### 6.4 交互反馈

- 所有可点击元素有 `hover` / `active` 态。
- 异步操作有 loading 态，操作成功有 Toast（1.5s 自动消失）。
- 长操作（> 1s）显示进度或骨架。
- 表单校验实时反馈（失焦校验），提交时整表校验。

### 6.5 无障碍（P2）

- 所有图片有 `alt`。
- 可交互元素支持键盘 Tab 聚焦。
- 播放器按钮有 `aria-label`。
- 对比度符合 WCAG AA（暗色模式下重点校验）。
