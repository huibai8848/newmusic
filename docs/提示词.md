【项目名称】
[例如：MusicLive 在线音乐社交平台]

【一句话定位】
一个支持在线听歌、AI 搜索与推荐、音乐房实时互动、用户社交互动、内容安全与数据运营的 Web 音乐平台。

【技术栈】
后端：Spring Boot + MyBatis / MyBatis-Plus + MySQL + Redis + WebSocket + Spring Security + JWT + Elasticsearch + IK 分词 + AI 大模型 API + 消息队列。
前端：React + TypeScript + Vite + Ant Design + Axios + Zustand / Redux + WebSocket。
数据与运维：Redis Cluster、Kafka / RocketMQ / RabbitMQ、Prometheus + Grafana、ELK、SkyWalking、Docker + Nginx、Swagger / Knife4j。
AI 与推荐：大模型 API 可插拔、向量库 Milvus / RedisSearch、推荐召回与排序、AB 测试、埋点系统。
说明：如果某些技术不确定，请标注“假设”，并给出可选方案。

【用户角色】
1. 游客：浏览歌曲、搜索、试听、查看公开歌单和音乐房。
2. 普通用户：注册登录、听歌、评论、收藏、分享、创建歌单、加入音乐房、使用 AI 推荐、私信、发动态。
3. 音乐房房主 / 管理员：创建房间、管理房间、控制播放、禁言、踢人、设置管理员、排麦、房主转让。
4. 平台管理员：管理用户、歌曲、歌手、专辑、歌单、评论、房间、举报、审核、统计。
5. 超级管理员：权限分配、系统配置、操作日志、敏感操作审批、AB 测试配置。
6. 运营人员：配置推荐位、运营报表、用户画像、活动歌单、内容审核。

【核心功能需求】
请按模块详细展开，每个功能都要写清楚：功能目标、使用角色、前置条件、操作流程、业务规则、异常情况、验收标准、优先级 P0/P1/P2。

1. 数据库 CRUD
- 歌曲、歌手、专辑、歌单、分类、标签、歌词、评论、用户、音乐房、动态、私信、通知等实体的增删改查。
- 支持分页、条件筛选、模糊搜索、批量操作、逻辑删除、创建时间 / 更新时间。
- 使用 MyBatis / MyBatis-Plus 实现，统一响应格式。

2. 前端界面
- React 实现 PC Web 端，后续可扩展移动端 / PWA。
- 页面包括：首页、登录注册、搜索页、歌曲详情、歌单页、播放器、音乐房、个人中心、用户主页、私信页、动态流、管理后台、数据看板。
- 播放器需要全局状态管理，支持跨页面持续播放。
- 界面要求响应式、暗黑模式可选、组件化、易扩展。

3. Redis
- 缓存歌曲详情、热门歌单、排行榜、搜索热词、验证码、登录会话。
- 统计播放量、点赞数、收藏数、评论数、粉丝数。
- 接口限流、分布式锁、音乐房在线状态、WebSocket 会话状态。
- 说明缓存穿透、缓存雪崩、缓存一致性处理策略。
- 支持 Redis Cluster 部署方案。

4. WebSocket
- 音乐房实时聊天、弹幕、在线用户列表、房间公告。
- 同步播放：播放、暂停、切歌、进度校准。
- 系统通知、评论回复通知、房间邀请通知、私信提醒、@提醒。
- 说明心跳检测、断线重连、消息可靠性和消息格式。
- 说明 WebSocket 集群下如何通过消息队列广播消息。

5. 音乐房
- 创建房间、加入房间、退出房间、公开 / 私密 / 密码房。
- 房主、管理员、普通成员权限区分。
- 麦位、排麦、上麦、下麦、禁言、踢人。
- 播放队列、房主控制播放、同步播放、聊天、弹幕、房间公告。
- 房间人数限制、房间状态、房间关闭与解散。

6. 音乐搜索 + AI
- 关键词搜索：歌曲名、歌手、专辑、歌词、标签。
- 使用 Elasticsearch + IK 分词，支持自定义词典、停用词、同义词、拼音搜索。
- 搜索历史、热搜榜、搜索联想、结果筛选、结果排序。
- AI 搜索：支持自然语言，例如“适合跑步的周杰伦快歌”“适合睡前听的轻音乐”。
- AI 搜索需要做意图识别、关键词抽取、条件补全、结果解释。

7. 音乐基础播放与歌词
- 播放、暂停、上一首、下一首、进度条、音量、播放模式。
- 播放列表、当前播放队列、播放历史、最近播放。
- LRC 歌词解析、滚动歌词、逐字歌词、歌词偏移校准。
- 播放失败重试、音频加载状态、错误提示。

8. AI 智能推荐
- 每日推荐、猜你喜欢、相似歌曲、场景歌单、情绪歌单。
- 基于播放、收藏、评论、分享、跳过等行为推荐。
- 可结合协同过滤、内容标签、向量召回、大模型重排。
- 推荐结果要有推荐理由，例如“因为你收藏了周杰伦”。
- 支持冷启动推荐、热门推荐、编辑精选。

9. 管理员管理功能
- 用户管理：封禁、解封、角色分配、重置密码。
- 内容管理：歌曲、歌手、专辑、歌单、歌词、评论、房间、动态。
- 审核管理：歌曲审核、评论审核、举报处理、敏感词过滤、AI 审核、人工复审。
- 推荐配置：热门推荐、首页轮播、榜单配置、AB 测试配置。
- 统计看板：用户量、播放量、活跃度、房间数、评论数、收入 / 会员数据。
- 操作日志、登录日志、异常日志、权限控制。

10. 基础社交功能
- 用户评论、回复评论、点赞、取消点赞、收藏、取消收藏、分享。
- 关注、粉丝、私信、消息通知、@提醒。
- 举报评论、举报用户、举报房间。
- 评论排序、敏感词过滤、评论审核。

11. IK 分词
- 用于歌曲名、歌手名、歌词、标签、评论的搜索分词。
- 支持自定义音乐词典、歌手词典、网络热词。
- 支持同义词、停用词、拼音、简繁转换。
- 说明 IK 分词与 Elasticsearch 的集成方式；如果不用 ES，请给出替代方案。

12. 音乐播放升级
- 音质切换：标准、高清、无损。
- 倍速播放、后台播放、离线缓存、下载管理。
- 跨设备同步播放进度、播放列表同步。
- 均衡器、音效、睡眠定时、频谱可视化、歌词可视化、快捷键。
- PWA 支持、移动端适配、播放器主题。

13. 音乐房升级
- 同步进度校准、弹幕、礼物、麦位、排麦、房间密码、房主转让。
- 房间内播放队列投票、点歌、切歌申请、房主审核。
- 房间公告、房间管理员、禁言列表、黑名单。
- 房间热度、房间榜单、房间推荐、房间历史记录。
- 支持多人实时互动和弱网优化。

14. AI 增强
- AI 歌单生成：根据自然语言、情绪、场景、歌手、年代生成歌单。
- 歌词翻译：支持多语言歌词翻译，保留时间轴。
- 歌词摘要：自动总结歌词主题、情绪和故事。
- 情绪识别：识别歌曲情绪，用于推荐、歌单、音乐房氛围。
- 哼唱识曲：用户哼唱片段，系统识别歌曲并返回结果。
- 说明 AI 模型调用、缓存、降级、成本控制和内容安全。

15. 推荐升级
- 多路召回：热门召回、标签召回、协同过滤召回、向量召回、关注召回。
- 排序模型：粗排、精排、重排，支持大模型重排。
- 冷启动：新用户、新歌曲、新歌单的推荐策略。
- AB 测试：实验分组、指标统计、流量分配、效果对比。
- 埋点系统：曝光、点击、播放、收藏、分享、跳过、完播等事件采集。
- 推荐结果可解释，支持推荐理由和反馈入口。

16. 社交升级
- 私信：单聊、消息已读、未读、撤回、敏感词过滤。
- 动态：发布文字、图片、歌曲、歌单，支持点赞、评论、转发。
- 关注流：关注用户动态、好友动态、推荐动态。
- @提醒：评论、动态、音乐房中 @ 用户并通知。
- 用户主页：头像、昵称、简介、歌单、动态、粉丝、关注。
- 粉丝榜：粉丝数、贡献榜、活跃榜、房间粉丝榜。

17. 数据平台
- 播放埋点：播放、暂停、切歌、完播、跳过、收藏、分享。
- 用户画像：兴趣标签、活跃度、付费意愿、情绪偏好、场景偏好。
- 热力图：歌曲热度、歌手热度、歌单热度、房间热度、时段热度。
- 运营报表：日活、月活、留存、播放量、评论量、房间数、转化率。
- 支持 ClickHouse / Doris / MySQL 汇总表等方案，标注假设。

18. 内容安全
- 敏感词：本地词库、DFA 算法、变体识别、拼音识别。
- AI 审核：文本、图片、音频、评论、动态、私信、房间聊天。
- 人工复审：审核队列、通过、拒绝、封禁、申诉。
- 举报处理：举报类型、处理流程、处理结果通知。
- 版权检测：歌曲版权、歌词版权、用户上传内容版权。

19. 高可用
- Redis 集群：主从、哨兵、Cluster、缓存降级。
- 消息队列：Kafka / RocketMQ / RabbitMQ，用于异步解耦、通知、埋点、推荐、审核。
- 服务降级：核心功能优先，非核心功能可降级。
- 熔断限流：Sentinel / Resilience4j / Hystrix，接口限流、熔断、重试。
- 监控告警：Prometheus + Grafana + SkyWalking + ELK，监控 CPU、内存、QPS、RT、错误率、WebSocket 连接数、MQ 堆积。
- 日志追踪：TraceId、链路追踪、异常告警、值班机制。
